# 1P备份助手 · 使用说明

一个全中文的原生 macOS 备份小程序，把 age 的加密、解密与校验放进一个窗口。不用碰终端。

- **加密**只需要公钥——所以加密备份这件事本身不接触任何秘密。
- **解密**读本机私钥，选择文件后确认执行。
- 内置 age v1.3.2 二进制（arm64），不联网、不依赖 Homebrew。
- 2.0 界面使用 SwiftUI 与系统原生 Liquid Glass，不包含 React、Electron、远程网页或第三方界面运行时。
- 最低构建目标为 **macOS 26.0，且仅支持 Apple Silicon Mac（M 系列芯片）**；本机在 macOS 27.0.1 验证，尚未在 macOS 26 真机验证。不支持 Intel Mac。
- 窗口右上角可选择跟随系统、浅色或深色外观。

---

## 一、安装

把 `1P备份助手.app` 拖进「应用程序」文件夹。

首次打开如果系统提示**"无法验证开发者"**：在图标上右键 → 打开 → 再点"打开"。
（程序是本机编译的，没有做苹果公证，这不影响它正常工作。）

---

## 二、第一次使用：生成密钥（只做一次）

打开程序 → 左侧 **「密钥与恢复」→「生成密钥」**。如果已有密钥，不需要重新生成。

会得到一对密钥：

| 文件 | 位置 | 性质 |
|---|---|---|
| `public.key` | `~/Library/Application Support/1P备份/` | 公钥，**不是秘密**，可以随便贴 |
| `private.key` | 同上，权限 600 | 私钥，**丢了所有备份都打不开** |

### 然后把私钥备份到别处

点「打开密钥文件夹」，把 `private.key` 复制到：

- 外置硬盘一份
- U 盘一份（放在**另一个地方**，别和外置硬盘放在一起）
- 云端可再放一份**用独立强口令加密的私钥副本**（不同的厂商/账户体系，别和 1Password 用同一个身份）；不要上传明文私钥。

> 建议所有离机的私钥副本都加一层口令，尤其是云端和随身 U 盘。这是**一次性**的命令：
>
> ```bash
> age -p -o ~/Desktop/private.key.age ~/Library/Application\ Support/1P备份/private.key
> ```
>
> 之后 U 盘上放 `private.key.age` 就行，别人拿到没有口令也打不开。
> （这条命令需要你另外装一份 age，比如 `brew install age`。）

加密私钥的口令不要只存在这份 1Password 密码库里，否则会形成“解密备份需要先打开备份”的死循环。单独保存恢复口令，并实际试解密一次私钥副本。

## 三、每月备份

1. 1Password → 文件 → 导出 → 选账户 → 输密码 → **1PUX** 格式 → 存到桌面。
2. 在 **「加密备份」** 页面拖入导出的 `.1pux`，或点「选择文件」（快捷键 `Command-O`）。也可拖到 App 图标上，自动切换至加密页面。
3. 确认所选文件后点 **「加密并生成校验文件」**。得到同目录下的同名 `.age` 文件，外加一个 `.sha256` 校验文件；结果页可复制摘要或在访达中显示。
4. 把 `.age` 和 `.sha256` 一起传到 NAS，从 NAS 下载回来校验；首次使用、换密钥或换电脑后，还应做下面的恢复演练。确认备份可用后，**删掉明文 `.1pux`**。

需要恢复时：在 **「解密恢复」** 页面选择 `.age`，点「解密到当前文件夹」，得到 `.1pux` 后再导入 1Password。拖到 App 图标上会自动路由，但**不会未经确认就开始处理**。一次只处理一个文件。

### 首次使用 / 换电脑后的恢复演练

1. 点「密钥与恢复 → 运行自检」，确认本机公钥和私钥配对。
2. 将一份真实的 `.age` 备份复制到**空文件夹**，在「解密恢复」页面选择并确认解密，避免与原来的 `.1pux` 同名。
3. 与原始导出文件逐字节比较，必要时在隔离的测试保险库检查导入结果；不要为了测试向日常保险库重复导入。
4. 确认离机保存的私钥副本也能恢复后，删除演练产生的明文。

SHA256 校验和自检不能替代真实备份的恢复演练。删除文件也不等于在 SSD、快照和云同步历史中安全擦除；导出时避免使用会同步到云端的目录，并启用 FileVault。

### 定期体检（建议每年一次）

加密不等于不会坏。硬盘上的文件会随时间悄悄损坏（bit rot），等你哪天要恢复才发现就晚了。

左侧的 **「校验备份」** 就是干这个的：选一个 `.age`，点「开始校验」，它会和旁边的 `.sha256` 核对，不解密、不需要私钥，确认文件是否与校验记录一致。每年把 NAS 上的备份下载下来逐个校验，并定期抽样解密。

注意：这不是数字签名，无法识别 `.age` 与 `.sha256` 被同时替换的情况，也不证明你保管的私钥能解密。

## 四、用「快捷指令」做一个版本（可选）

如果你更希望它在右键菜单里，可以自己搭一个，大约五分钟：

1. 打开「快捷指令」→ 新建。
2. 右侧边栏「快捷指令详细信息」→ 勾选 **用作快速操作**，接收 **文件**，位置选 **访达**。
3. 添加动作 **「运行 Shell 脚本」**，输入传递方式选 **作为自变量**，Shell 选 `/bin/bash`，脚本粘贴：

```bash
H="/Applications/1P备份助手.app/Contents/Resources/helper.sh"
set -e
for f in "$@"; do
  case "$f" in
    *.age) /bin/bash "$H" decrypt "$f" ;;
    *)     /bin/bash "$H" encrypt "$f" ;;
  esac
done
```

4. 再加一个 **「显示通知」** 动作，内容写「已完成」。
5. 存成「1P备份」，之后在访达里右键任意文件 → 快速操作 → 1P备份。

它使用的密钥和上面完全一样，两种方式可以混用。

## 五、常见问题

**我之前已经把私钥用口令包起来过（有 `.age` 后缀的私钥），程序能用吗？**
不能，程序只认未加密的私钥文件。用一次性命令还原：

```bash
age -d -o private.key 你那个私钥.age
```

然后把 `private.key` 放进 `~/Library/Application Support/1P备份/`。

**本机私钥为什么是明文？**
靠 FileVault 全盘加密和 600 文件权限降低风险，但它们不能阻止以你本人身份运行的恶意程序读取私钥。不要把这理解为等同于有口令保护的 SSH 私钥；离机的副本应另外用口令加密。

**换电脑怎么恢复？**
把私钥放进新机器的同一位置，打开「密钥与恢复」点「从私钥恢复公钥」，不会换一把私钥。先做自检和真实备份恢复演练。满足本页开头系统要求时，部署只需复制 `.app`；否则可直接使用兼容那台机器的 age 解密，备份格式不依赖本 App。

**只有公钥还在，私钥丢了怎么办？**
公钥仍可用于加密，但不能恢复私钥。程序会拒绝在这种状态下重新生成密钥，以免误以为新密钥能恢复旧备份。请先找回原来的私钥副本。

**提示"目标已存在，没有覆盖"**
同名的输出或 `.sha256` 已经在了（符号链接和文件夹也算）。这是故意的保护，防止误覆盖历史备份。请保留已有文件，检查后为输入改名，或换到空文件夹再来。

**程序被强制退出 / 电脑断电后怎么办？**
加解密先写同目录下权限受限的 `.1p-backup.*` 临时目录，成功后才发布最终文件；普通失败和正常终止会清理临时目录。强制结束或断电可能留下临时目录和 `*.1p-lock` 空锁目录。确认没有任务运行后再清理这些残留；解密临时目录可能含明文，不要上传或分享。若已有 `.age` 但没有 `.sha256`，先保留原文件与密文，换空文件夹重新加密，勿把它当成一次完整成功的备份。

**导出的备份里有 passkey 吗？**
没有。1Password 桌面端导出不含 passkey，这是官方限制，不是本程序的问题。

## 七、开发者回归测试

安装 Python 3 后，在本文件所在目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s 源码 -p test_helper.py -v
```

测试使用临时目录、临时密钥和模拟数据，不读取实际的 `~/Library/Application Support/1P备份/`。日常使用 App 不需要 Python。

原生界面源码在 `源码/Native/`，`源码/主程序.applescript` 保留为旧界面参考。使用带 macOS 26 或更新 SDK 的 Xcode/命令行工具构建：

```bash
bash 源码/Native/build.sh
```

构建产物位于 `.build-native/1P备份助手.app`，不会直接覆盖根目录的 App。界面使用系统框架，没有新增开源代码依赖。视觉方向参考了 `rdev/liquid-glass-react` 的玻璃分层理念，实际渲染由 Apple SwiftUI 的 `glassEffect` 完成，不包含或复制该库代码。

旧版 App 已保存在 `历史版本/1P备份助手-经典界面.app`。新版与旧版共用原有密钥位置和 age 文件格式。
